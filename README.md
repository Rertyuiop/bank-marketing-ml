# Прогноз отклика клиентов банка на предложение о вкладе

**Задача:** выбрать, кому из клиентов звонить с предложением открыть вклад, чтобы получить больше согласий при меньшем числе звонков.
**Данные:** UCI Bank Marketing, 45 211 клиентов, 11,7% согласий.
## Результаты

| Модель                  | ROC-AUC | PR-AUC |
| ----------------------- | ------- | ------ |
| Логистическая регрессия | 0.774   | 0.409  |
| Случайный лес           | 0.799   | 0.443  |
| XGBoost                 | 0.796   | 0,456  |

## Выводы при анализе датасета

- Признак `duration` (длительность звонка) становится известен только после получения целевой переменой. При его добавлении улучшаются метрики, но ухудшается реальное качество модели.
- Признак `day_of_week` является днем месяца. Конверсия не показала схожестей, исходя из которых было можно разделить признак на группы (пример: начало месяца, середина и конец), поэтому признак был взят как категориальный.
- Метрика accuracy не подходит для данного датасета из-за дисбаланса классов.
- ROC-AUC дает более точную картину, но так же, как и accuracy, подвержен искажению из-за дисбаланса классов.
- PR-AUC показывает наиболее точную картину.
